# QuizCraft 
 
An interactive Python Quiz Application with different Quiz Sections and Command Line Interface. 
 
## Features 
 
* TV Series Quiz Section 
* Indian Cricket Quiz Section 
* Mathematics Quiz Section 
* Interactive Main Menu 
* Score Calculation Automatically 
* Feedback for Correct/Incorrect Answers

text

## Technologies Used 
 
* Python 3 
* VS Code 
 
## How to Run 
 
1. Clone or Download this Repository. 
2. Open this Project Directory in VS Code. 
3. Run the following code in Terminal. 
 

bash 
python main.py
 
 
4. Select any Quiz section from the Main Menu.
